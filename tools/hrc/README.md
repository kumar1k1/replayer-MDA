# Разбор решений HRC (.hrcv) без HRC — черновик (отложено)
- .hrcv = zip: settings.json, state.json, gametree.dat, nodedata.dat, idx.dat.
- idx.dat: по 2 записи (u64 смещение, u32 длина) на узел; число узлов = первое u32 gametree.dat (15 BB: 134 836). Нечётная запись — данные узла в nodedata.dat (у постфлоп-узлов длина 0).
- Блок узла: заголовок 36 байт (…, 23, 169, …), затем 169 строк по (2n+1) float32, n — число действий; последние n значений строки — накопленные частоты стратегии (нормировать).
- Порядок рук: по возрастанию 2→A, матрица 13×13 по строкам, выше диагонали — разномастные, ниже — одномастные.
- Узлы 0–5 = первые ходы UTG…BU (fold / raise 2 BB / all-in). Сверено с селфплеем 15 BB: среднее расхождение 0,1–0,5 % на руку.
- НЕ разобрано: gametree.dat (какой узел какой линии соответствует) — нужно для остальных веток.
