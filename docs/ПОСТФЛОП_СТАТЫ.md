# Постфлоп-статы (по поп-апу Hand2Note владельца, 20.11.2026)

Цель: для каждого игрока, кластера и топов — те же статы, что в поп-апе Hand2Note владельца, чтобы цифры совпадали
с трекером. Считаются одним проходом по базе (счётчики «возможность / сделал»), лучше вместе со следующим большим
проходом. Проверка: сверка с Hand2Note на руках владельца — цифры должны совпасть.

## Обозначения
F / T / R — флоп / тёрн / ривер; T+R — тёрн и ривер вместе; маленькие цифры — выборка; цвет — отклонение от нормы.
IP / OOP — в позиции / без позиции. [as 3b] — мы 3-бетили; [as C] — мы коллировали 3-бет.

## Блоки
- Префлоп: UO pre 30bb+ и 15-40bb (RFI, RFI >2.4, F3B NAI, C3B NAI, 4bet по позициям), COLD CALL и 3BET NAI против
  позиции опена, BTN Fold vs SQZ, SQZ NAI по сочетаниям позиций, VS STEAL [2-2.2bb] (BB/SB против BTN/CO/MP/EP: фолд,
  колл, 3-бет, 3-бет не в олл-ин, олл-ин, олл-ин 15–35 bb), ISO (vs 1 L, /Fold — изолейт, потом фолд на ререйз),
  3BET vs ISO, LIMP, SB vs BB (L, L/F, L/C, L/3B, VPIP), BB vs SB (фолд против рейза 2–2.5 / 2.5–3 / 3–4, ISO vs SB, ISO/FOLD).
- Рейзер префлопа: RvBB, RvSB, RvCC (против защитника BB / SB / колд-коллера). Коллер: BBvsR, SBvsR, CCvsR.
  3bet Pot, ISO Postflop, Multyway Pot (рейзер IP / OOP, коллер IP, BB против PFR / CC), BB [OOP][3way] / [HU]: X-X-X, X-X-B.
- Действия: CB (и по размерам <35% / 35–65% / >65% банка), CB-F / CB-C / CB-3B (продолжил, получил рейз: фолд / колл /
  3-бет), CB-X-B / CB-X-X (бет — чек — бет / бет — чек — чек), Skip CB (чек вместо продолжения), Delay CB (отложенное
  продолжение), F / C / XR / R vs CB (и по размерам), F / R vs Probe, Probe bet (и [<40%]), F / R vs Donk, Donk vs 1 / 2
  players, DONK/F, B vs Skip (ставка коллера в позиции, когда рейзер прочекал), X vs Skip, F / R vs Delay, F vs B-X-B,
  B vs XX/XXX, River Bet, F / C vs River Bet, Bet% River and WON (по размерам 10–39 / 40–55 / 56–85 / 86–100 / 101+ % банка).

## Уточнено владельцем
- «+Bet» под XR (блок RvCC: строки «XR» и «+Bet»): из тех раз, когда мы чек-рейзнули (и соперник заколлировал),
  как часто поставили и на следующей улице (тёрн).
- «+Bet Turn / +Bet River» у защитника (BBvsR, SBvsR — строки сразу под «XR vs CB»): +Bet Turn — после своего
  чек-рейза флопа как часто ставим на тёрне; +Bet River — после чек-рейза флопа и ставки на тёрне как часто ставим
  и на ривере (линия чек-рейз — бет — бет).
- Skip CB (рейзер против колд-коллера): как часто играем чек вместо продолжения.
- Skip CB-F: по сути чек-фолд — без позиции чек, на ставку соперника в наш чек — фолд.
- Bet% River and WON: как часто ставим на ривере этим размером и выигрываем банк.

## Открытые вопросы (разобрать, когда дойдём до постфлопа)
- Bet% River and WON: по мнению владельца — скорее всего только когда ставку заколлировали и дошло до вскрытия
  (из ставок этого размера, которые уравняли, — какая доля выиграна; низкий процент на крупных размерах = много блефа).
  Считаем так, подтвердить сверкой с Hand2Note на руках владельца.
- Лучше всего — выгрузить определения пользовательских статов из Hand2Note (фильтры) и считать один в один.

## Дерево линий (Hand2Note → Free Position, вкладки RvsBB / RvsSB / RvsCC / CCvsR / BBvsR / SBvsR, BvB) — 20.11.2026
Основа постфлоп-этапа. Слева направо — улицы; жёлтое — действие соперника, белое с % — наше действие и частота;
F / C / R — наш ответ фолд / колл / рейз; B|X|B, X|X|X — вся линия по трём улицам.
Пример RvsBB (мы рейзер против BB), владелец: Cbet флоп 79 (на рейз F31 C45 R26) → тёрн после колла и чека: Cbet 64
(на рейз F49 C43 R15) → ривер Cbet 62 (на рейз F99) / X 38 (на ставку F35 C47 R20); тёрн X 36 → ривер против Probe
F52 C34 R14, против чека B|X|B 40 / B|X|X 60; ставка соперника на тёрне F29 C54 R19, ривер F36 C64.
Флоп X 21 → тёрн Probe F26 C54 R20 → ривер X|C|B 59; тёрн Delay CB 57 (на рейз F47) → X|B|B 49 / X|B|X 51;
тёрн X|X 42 → ривер X|X|X 45 / X|X|B 55, против ставки X|X|F 44. Донк: флоп F24 C45 R36, тёрн F33 C30 R37, ривер F44 C48 R15
(сумма не всегда 100 — разные знаменатели или малая выборка; проверить при сверке).
Что считаем в каждом узле дерева для игрока, кластера, топов: частота, выборка (сколько раз дошли до узла), результат
линии по базе (EV топов в этом узле — чего нет в Hand2Note), разбивка по размерам ставок (<35 / 35–65 / >65% банка).
