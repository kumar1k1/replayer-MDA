# Полный прогон на вашем ПК (п.10)

1. Скачайте проект: GitHub → kumar1k1/replayer-MDA → Code → Download ZIP. Распакуйте в `D:\маининг\replayer-MDA`.
2. Запустите `ЗАПУСК.cmd` двойным щелчком. Окно не закрывайте; ПК не должен засыпать (Параметры → Питание → «Никогда»).
3. Что происходит (около 15–20 ч на всей базе, 100 млн раздач):

| шаг | что | время |
|---|---|---|
| 1 | статы игроков (весь проход) | 4–6 ч |
| 2 | кластеры | минуты |
| 3 | топы (≥ 3000 рук, перекрёстно A/B) | минуты |
| 4 | сайзинги (каждая 4-я раздача; архивы всё равно распаковываются целиком) | 2–3 ч |
| 5 | лайнап (каждая 4-я раздача) | 2–3 ч |
| 6 | модель v8 (весь проход, продолжает с последнего архива) | 5–7 ч |
| 7 | сборка реплеера `app\dist` | минуты |
| 8 | проверка движка и итог `pipeline\out\ИТОГ_ПРОГОНА.md` | 10–20 мин |

- Прервался (выключили ПК, ошибка) — запустите снова: сделанные шаги пропускаются (флажки `*.flag` в `pipeline\out`).
- Памяти Node даётся 12 ГБ. Если на ПК 16 ГБ и меньше и Node падает с «heap out of memory» — перед запуском `set MEM=8192`.
- Нужен Node.js (есть: им работает Backing). Архивы берутся из `D:\маининг\реплеер\raw` и `raw-ps`, как у Backing; `2608-PS-.rar` пропускается.
4. После прогона скажите мне — я заберу `pipeline\out` (отчёты и модель) и проверю всё (п.11).
