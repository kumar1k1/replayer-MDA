# Алгоритм v8 — модель префлопа и подсказка (п.8)

Основа и формулы EV — как в v7 (`docs/АЛГОРИТМ_v7.md`): EV относительно фолда, поправка на олл-ин, разложение «все сфолдили / банк разыгран», точный пуш и колл пуша через эквити, частоты топов по рейтингу рук. Ниже — только то, что поменялось.

## Конвейер (порядок запуска)
1. `pipeline/passStats.cjs` — статы игроков (11 статов тренера по половинам A/B и форматам) + префлоп-счётчики по бандам (для лайнапа).
2. `pipeline/clusters.cjs` — 20 кластеров тренера, поправка 6-max, стягивание, надёжность, объединение ников.
3. `pipeline/tops.cjs` — топы tops_A (отбор по половине A) и tops_B (по B).
4. `pipeline/sizes.cjs` — таблица сайзингов пула и топов → `data/sizes_v8.json`.
5. `pipeline/lineup.cjs` — модель лайнапа и её калибровка → `data/lineup_v8.json`.
6. `pipeline/passV8.cjs` — модель EV → `out/model_v8.json`.

## Что изменилось против v7
| | v7 | v8 |
|---|---|---|
| группа игрока | файлы Backing (top/areg/preg/fish) | кластеры тренера → reg / nit / fish / superfish |
| топы | половина A, модель только на половине B | перекрёстно: раздача половины A — топовая, если игрок в tops_B, и наоборот; вся база в деле |
| стек в ключах EV | 15 корзин s1…s15 | банды владельца по эффективному стеку; диапазоны пуша/колла — на мелкой сетке (пуш 4 и 11 bb — разные диапазоны) |
| действие | класс + сайз (open:x2.2 …) | класс (open / iso / 3bet / 4bet / call / limp / shove); сайз — `lib/sizing.js` по топам |
| эффективный олл-ин | считался рейзом | это пуш |
| P(все сфолдят) после опена | средняя частота спота | по конкретным игрокам за спиной (`lib/lineup.js`) с поправкой на позицию и размер |
| P(все сфолдят) после 3-бета | спот | спот × фолд к 3-бету именно этого открывшего (отношение шансов игрок/пул) |
| колл пуша первым | частота спота AI | по конкретному игроку (лайнап, с поправкой на позицию пушера) |
| колл пуша поверх рейза | частота спота AI | спот × склонность игрока коллировать олл-ины |
| лимит без данных | совета нет | ближайшая страта с данными, в подсказке — пометка |
| рейз ≥30% эфф. стека | считался рейзом | заменяется пушем (порог проверен по данным, п.6) |
| порядок действий в диапазоне топов | пуш — всегда сильнейшее | глубже 25 bb пуш идёт после рейза: премиум-руки топы играют рейзом |

## Движок (`engine/engine_v8.js`)
`create(model, eq169, {sizes, lineup})` → `advise(spot, cards, info)`, где `info(seat) → {pf, cl}` — счётчики и кластер игрока на этом месте (нет — пул).
Возвращает варианты с EV, P(все сфолдят) и источником; для рейзов — рекомендуемый размер (`size.to` bb, корзина, доля у топов), совет `rec` (`rec.ru`: «3-бет до 8 bb»), страту и пометку, если взята соседняя.
`verdict(adv, act, sz)` — оценка фактического действия, в т.ч. «тот же класс, другой сайз».
