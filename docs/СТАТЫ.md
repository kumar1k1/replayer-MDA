# Определения статов (согласовано с владельцем)

Все статы считаются **по возможностям**: стат = (сколько раз сделал) / (сколько раз мог). Каждый стат — по бандам эффективного стека [0;12) · [12;20) · [20;36) · [36;60) · [60;100) · [100;150) · [150;∞). Ключ игрока — «рум:ник».

## Статы атласа «Бублик» (для кластера)
| Стат | Определение | Источник |
|---|---|---|
| VPIP | добровольно вложил префлоп (колл / лимп / рейз) / раздачи, где был ход префлоп | стандарт |
| PFR | рейз префлоп / раздачи, где был ход префлоп | стандарт |
| WS / WN / LS / LN | исходы **увиденных флопов в банке 1 на 1**: выиграл на вскрытии / выиграл без вскрытия / проиграл на вскрытии / проиграл без вскрытия; сумма = 100% | владелец, 15.11 |
| WTSD / W$SD | дошёл до вскрытия / увидел флоп (1 на 1); выиграл на вскрытии / дошёл до вскрытия | стандарт |
| Отложка (Delay) IP / OOP | был префлоп-рейзером, банк 1 на 1, на флопе оба прочекали (без кбета), **поставил терн** / такие ситуации; отдельно в позиции и без | владелец, 15.11 |
| FvRaise IP / OOP | поставил кбет, получил рейз, **сфолдил** / кбет получил рейз; отдельно в позиции и без | владелец, 15.11 (улица — уточнить: флоп или любая) |
| A/D post | нет определения — в классификацию не входит, пока не согласовано | — |
| BB/100 | итог в bb на 100 рук; учитывается только при ≥ 3000 рук | владелец, 15.11 |

## Префлоп-статы (для подсказок и лайнапа)
RFI по позициям; фолд / колл / 3-бет на опен (позиция против позиции); фолд / колл / 4-бет на 3-бет; сквиз; колд-колл; колд-4-бет; лимп; изо против лимпа; ответ лимпера на изо; защита ББ; BvB; пуш первым; колл пуша. Точные определения возможностей — при реализации (п. 3), с раздачами-примерами в тестах.
